# STAR: Secure Targeted Activation Regulator for Agentic Privacy Protection in LLMs

This repository contains the official code and evaluation framework for **STAR** (*Secure Targeted Activation Regulator*), an inference-time activation-steering mechanism designed to regulate agentic cooperation and mitigate privacy leakage in Large Language Models.
